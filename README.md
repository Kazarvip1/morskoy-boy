# Морской бой — онлайн

Мобильная веб-игра для двух игроков: комнаты по ссылке, скрытые поля, пошаговая стрельба, чат, звуковые сигналы и локальная статистика.

## Запуск на компьютере

Требуется Node.js 18 или новее.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Публикация, чтобы друзья играли по ссылке

Самый простой вариант — развернуть проект как Node Web Service на Render:

1. Создайте репозиторий GitHub и загрузите в него все файлы этой папки.
2. В Render выберите **New → Web Service** и подключите репозиторий.
3. Render распознает `render.yaml`. Если настройки не подхватились, укажите:
   - Build Command: `npm install`
   - Start Command: `npm start`
4. После публикации откройте выданный HTTPS-адрес. Создайте комнату и отправьте другу ссылку, которая появится в игре.

Для другого Node-хостинга используйте `npm install` и `npm start`; хостинг должен поддерживать WebSocket/Socket.IO и задавать переменную `PORT`.

## Правила

- Поле 10×10.
- Флот: 1×4, 2×3, 3×2, 4×1.
- Корабли не соприкасаются, в том числе по диагонали.
- Попадание даёт дополнительный выстрел; промах передаёт ход.
- Статистика хранится локально в браузере конкретного игрока.

## Важно

Комнаты существуют в памяти работающего сервера. Перезапуск сервера завершит активные матчи. Это стартовая версия без аккаунтов и постоянного рейтинга.
